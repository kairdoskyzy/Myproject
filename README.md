# Мен туралы
Бұл менің алғашқы жобам. 
* **Менің атым:** Каирдосқызы Мөлдір
* **Менің жасым:** 16
* **Оқу орным:** Политехникалық колледж
* **Оқу мамандығым:** Бағдарламалық қамтамасыз етуді әзірлеу

# Менің қызығушылықтарым
Мен көбінесе бос уақытымда сериалдар қарайм немесе әпкеме барып екеуміз “ештене істемеумен” айналысамыз
